# 托业试题集

整理托业（TOEIC）试题和知识点的仓库。提供一道题后，AI 助手会把完整题目与详细题解加入试题集，并将语法、词汇、固定搭配等可复用知识独立归类到 `notes/` 下，方便练习和复习。

同时支持 **Claude Code** 和 **Codex**：核心指令写在 `AGENTS.md`（Codex 原生读取），`CLAUDE.md` 只用一行 `@AGENTS.md` 引入同一份指令，避免两份说明漂移。

## 怎么用

1. 打开 Claude Code 或 Codex。
2. 直接粘贴一道托业题（题干 + 选项，有正确答案或截图更好）。
3. 助手会将题目加入试题集，完成详细题解，并把知识点独立归类到 `notes/`。
4. 做题时查看 `01_试题集.md`，复习时查看其他分类笔记。

没粘题时助手不会主动改文件——可以正常向它提问，或让它帮你查笔记。

所有 `notes/` 笔记都采用追加模式：新试题写入试题集末尾；分类笔记中已存在的知识点只补充、不重复建条，也不与具体试题建立题号关联。

## 可视化查看

两种打开方式：

- **在线版 `index.html`**：通过 GitHub Pages 访问（`https://<用户名>.github.io/<仓库名>/`），运行时直接读取 `notes/*.md`，笔记内容一改、推上去就生效，无需重新生成。注意它靠 `fetch` 读文件，**不能本地双击打开**（`file://` 会被浏览器拦截）；本地预览可在仓库目录跑 `python3 -m http.server` 再访问。
- **离线版 `offline.html`**：把笔记内容打包进单文件，双击即开、离线可用、可发手机看。

在线版 `index.html` 是手维护的静态文件，不由脚本生成；新增 / 删除笔记文件时，手动更新它顶部的 `NOTE_FILES` 清单即可。离线版 `offline.html` 由 `notes/` 内容打包生成——新增 / 删除笔记文件后让 AI 重新生成一次即可（或在装了 Python 的环境运行 `python3 build.py`）；只改已有笔记内容时，两个版本都无需重新生成（在线版实时读、离线版重跑脚本才更新内容）。

## 文件结构

| 文件 | 内容 |
|------|------|
| `AGENTS.md` | 核心工作指令（Codex 原生读，Claude Code 经 CLAUDE.md 引入） |
| `CLAUDE.md` | 仅 `@AGENTS.md` 一行 |
| `notes/01_试题集.md` | 完整题目存档 + 详细题解 |
| `notes/02_高频词汇.md` | 词性、释义、题中例句、易混词 |
| `notes/03_固定搭配.md` | 动词介词搭配、固定短语 |
| `notes/04_语法点.md` | Part 5/6 语法考点：规则 + 例证 |
| `notes/05_长难句.md` | Part 7 长难句结构拆解 + 翻译 |
| `notes/06_商务场景表达.md` | 邮件 / 会议 / 合同等场景表达 |
| `notes/07_易混词辨析.md` | 形近、义近词辨析 |
| `index.html` | 在线查看器，运行时读 `notes/*.md`（供 GitHub Pages，手维护静态文件） |
| `offline.html` | 离线查看器（双击即开，自包含），由下方脚本生成 |
| `build.py` | 从 `notes/` 生成 `offline.html`（仅标准库） |

分类不够用时会新增文件，编号顺延并在此表登记。
