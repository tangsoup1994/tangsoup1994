# 07 易混词辨析

形近、义近词放一起辨析，讲清区别点（词义侧重、搭配、可数性、及物性……）。

| 易混词组 | 区别（侧重 / 搭配 / 用法） | 题中例句（英文原文） |
|----------|---------------------------|----------------------|
| rapid / bright / loud / proud | `rapid` 表速度快，能修饰 `expansion`；`bright` 表明亮、聪明或前景好，不表示扩张速度；`loud` 多指声音大或颜色醒目；`proud` 表自豪，通常修饰人或组织。 | has seen rapid expansion in East Asia |
| large / larger / largely / largest | `large` 是原级；`larger` 是比较级；`largest` 是最高级，和 `the ... of all` 搭配；`largely` 是副词，表示「主要地 / 很大程度上」，不能作最高级形容词。 | the largest of all the company’s retail locations |
| teach / taught / teaching / teachers | `teach` 是动词原形；`taught` 是过去式 / 过去分词；`teaching` 是动名词或现在分词，不表示复数人员；`teachers` 是复数名词，可作 `are` 的主语。 | Singh Design Institute’s teachers are active professionals |
| often / so / quite / too | `so` 可和 `that` 构成 `so + adj. + that` 结果结构；`often` 表频率；`quite` 只表示程度，不能和 `that` 呼应；`too` 常接 `to do` 表过度。 | so powerful that it can cut sheets of metal |
| special / specialization / specialize / specialist | `special` 是形容词；`specialization` 是抽象名词，表示专业化或专长；`specialize` 是动词；`specialist` 是表示人的名词，可作职位身份。 | financial specialist, Richard Bigsby |
| expertise / expert / expertly / experts | `expertise` 是不可数抽象名词，表示专业知识；`expert` 是单数可数名词，指专家；`expertly` 是副词；`experts` 是复数名词，不能和 `an` 搭配。 | an expert in climate science |
| establish / established / establishing / was established | `establish` 是动词原形；`established` 可作过去分词，表示被动后置定语；`establishing` 是现在分词，表示主动；`was established` 是完整谓语，不能放在已有谓语的句子中。 | a new environmental agency established to address the city’s pollution problem |
| designating / designated / designation / designate | `designated` 是过去分词形容词，表示「指定的」；`designating` 是现在分词，偏主动；`designation` 是名词；`designate` 是动词原形，不能直接修饰 `parking space`。 | designated parking space |
| whenever / through / including / once | `through` 是介词，可接时间段表示持续贯穿；`whenever` 和 `once` 是连词，后面要接句子；`including` 表包括，不表示持续时间。 | continue through the upcoming holiday season |
| soften / softness / soft / softly | `soft` 是形容词，可修饰 `materials`；`soften` 是动词，表示变软或使变软；`softness` 是名词，表示柔软性；`softly` 是副词，不能直接修饰名词。 | particularly soft materials |
| construction / building / processing / decision | `construction` 和 `under` 构成固定表达 `under construction`，表示正在建设中；`building` 可指建筑物或建造行为，但不说 `under building`；`processing` 多指订单、申请、数据处理中；`decision` 表决定，不能表达施工状态。 | under construction |
| accurately / temporarily / broadly / privately | `temporarily` 表暂时地，可修饰 `suspended` 说明服务临时暂停；`accurately` 表准确地；`broadly` 表广泛地或大体上；`privately` 表私下地或私人地，都不符合交通服务暂停语境。 | temporarily suspended |
| innovation / innovate / innovative / innovatively | `innovative` 是形容词，可修饰 `advertising campaign`；`innovation` 是名词，表示创新或创新成果；`innovate` 是动词；`innovatively` 是副词，不能直接修饰名词短语。 | innovative advertising campaign |
| plenty / most / many / every | `many` 可直接修饰复数可数名词；`plenty` 要用 `plenty of` 才能接名词；`most` 表大多数时需要范围限定；`every` 后接单数可数名词，不能接复数 `opportunities`。 | many opportunities |
| regards / is regarded / regarding / has regarded | `is regarded` 是被动语态，和 `as` 构成 `be regarded as`；`regards` 和 `has regarded` 是主动语态，后面需要宾语；`regarding` 是现在分词或介词，不能单独作谓语。 | is regarded as one of the most influential modern authors |
| deliver / delivered / delivers / delivery | `delivery` 是名词，可作定语修饰 `program`；`deliver` 是动词原形；`delivers` 是第三人称单数动词；`delivered` 是过去式 / 过去分词，常表示被送达的，不适合修饰 `program`。 | same-day delivery program |
| method / response / biology / excursion | `method` 表方法，能和 `for harnessing solar energy` 搭配；`response` 表回应或反应；`biology` 表生物学；`excursion` 表短途旅行，后三个都不符合利用太阳能的方法这一语境。 | method for harnessing solar energy |
| effect / effective / effects / effectively | `effective` 是形容词，可作 `be` 后表语，表示生效或有效；`effect` 和 `effects` 是名词；`effectively` 是副词，不能作表语形容词。 | be effective until next month |
| optimist / optimism / optimistic / optimistically | `optimistic` 是形容词，可修饰 `forecasts`；`optimist` 是乐观主义者；`optimism` 是乐观主义 / 乐观情绪；`optimistically` 是副词，不能直接修饰名词。 | optimistic forecasts |
| presentation / president / collection / diploma | `presentation` 表演示或发表，能被 `rehearse`，也能从同事处获得反馈；`president` 指人；`collection` 指收藏或系列；`diploma` 指文凭，后三个都不能作排练内容。 | rehearsed his presentation |
| enthusiastic / enthusiastically / enthusiast / enthusiasm | `enthusiasm` 是抽象名词，能放在所有格后作中心词，并和 `for` 搭配；`enthusiastic` 是形容词；`enthusiastically` 是副词；`enthusiast` 指热衷者这个人，不表示热情本身。 | enthusiasm for oil painting |
